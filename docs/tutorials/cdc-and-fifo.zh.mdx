本教程展示 Syl 如何在编译期静态拦截非法的跨时钟域（CDC）采样，以及如何正确使用 `@cdc_sync`、`std.cdc` 与 `std.fifo.SyncFifo`。

## 第一步：认识静态 CDC 检查

如果由 `clk_b`（`Clock<B>`）驱动的寄存器直接采样来自时钟域 `A` 的信号，`sylc check` 会在仿真前直接报出 `E_MIDDLE_CDC_VIOLATION`。

## 第二步：使用 `std.cdc.Sync2FF`

`std.cdc` 提供了基于 `@cdc_sync(in, out, dst_clk)` 构建的 `Sync2FF`、`Sync2FFAsyncLow` 与 `PulseSynchronizer`：

```syl
use std.cdc.Sync2FF

cell SyncedPipeline<A: Domain, B: Domain>(
    clk_a: in Clock<A>,
    clk_b: in Clock<B>,
    rst_b: in Reset<B, Sync, ActiveHigh>,
    in_bit: in Bit,
) -> out_bit: Bit {
    let s = place Sync2FF<B>(dst_clk: clk_b, dst_rst: rst_b, async_in: in_bit)
    out_bit := s
}
```

## 第三步：运行 `sylc check`

```bash
sylc check --std-root examples/std tutorial_cdc.syl
```
