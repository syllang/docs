# 第 2 课：时序计数器与仿真

在[第 1 课](/zh/docs/tutorials/first-cell)中，你构建了一个纯组合逻辑电路。但真实的数字系统需要状态——在时钟沿捕获数值并在复位时干净初始化的触发器（Flip-Flop）。本课将带你编写一个带时钟域参数的 8 位计数器 `Counter8`，解读其生成的 `always_ff` SystemVerilog 代码，并使用 **Verilator** 与 **C++17** 完成周期级功能仿真。

## 学习目标

完成本课后，你将能够：

- 使用 `D: Domain`、`Clock<D>` 与 `Reset<D>` 为 `cell` 参数化时钟域。
- 使用 `reg ... reset(rst, 0)` 声明寄存器状态，并用 `next` 驱动其次态输入。
- 理解 Syl 如何将 `reg` 降级为 SystemVerilog 中的同步 `always_ff @(posedge clk)` 逻辑。
- 编写并运行 C++17 Verilator testbench 验证时序电路行为。

## 前置条件

- 已完成[第 1 课](/zh/docs/tutorials/first-cell)。
- 已安装 `verilator` 与支持 C++17 的 `g++`。

## 第 1 步：时钟域参数化的 Clock 与 Reset

在 Verilog 中，时钟只是一根普通的 1 位 `logic` 线网——没有任何机制阻止你把 `clk_a` 域的寄存器连到 `clk_b` 域的复位信号上。Syl 在类型系统层面消除了这类隐患，将每个时钟和复位都绑定到**时钟域**类型参数 `D: Domain` 上：

- `clk: in Clock<D>`
- `rst: in Reset<D>`

由于 `clk` 与 `rst` 共享同一个 `D`，编译器就能静态保证它们属于同一个时钟域。（我们将在[第 5 课](/zh/docs/tutorials/cdc-and-fifo)中看到 Syl 如何拦截跨时钟域错误。）

## 第 2 步：编写 `Counter8`

创建 `counter8.syl`：

```syl
cell Counter8<D: Domain>(
    clk: in Clock<D>,
    rst: in Reset<D>,
    enable: in Bit,
    clear: in Bit,
) -> value: UInt<8> {
    reg count: UInt<8> reset(rst, 0)

    signal count_next: UInt<8> :=
        select priority {
            clear => 0,
            enable => count + 1,
            default => count,
        }

    next count := count_next
    value := count
}
```

### 硬件语义解析

1. **`reg count: UInt<8> reset(rst, 0)`**：声明一个 8 位触发器 `count`，当 `rst` 有效时初始化为 `0`。由于使用了 `rst`，`count` 自动绑定到 `rst`（以及 `clk`）所在的时钟域 `D`。
2. **`signal count_next: UInt<8>`**：计算组合逻辑次态。注意优先级顺序：`clear` 优先于 `enable`，两者均无效时 `default => count` 保持当前值。
3. **`next count := count_next`**：将 `count_next` 连接到 `count` 触发器的 `D`（数据）输入端。Syl 强制要求每个 `reg` 都必须有 `next` 驱动。
4. **`value := count`**：将触发器的 `Q` 输出持续驱动到输出端口 `value`。

运行检查并生成 SystemVerilog：

```bash
sylc check counter8.syl
sylc emit counter8.syl > Counter8.sv
```

## 第 3 步：解读生成的 `always_ff`

打开 `Counter8.sv`，可以看到：

```verilog
// Generated by sylc. MVP SystemVerilog subset.

module Counter8 (
    input clk,
    input rst,
    input enable,
    input clear,
    output [7:0] value
);
  reg [7:0] count;
  wire [7:0] count_next;
  assign count_next = /* priority */ (clear ? 0 : (enable ? (count + 1) : count));
  always_ff @(posedge clk) begin
    if (rst) begin
      count <= 0;
    end else begin
      count <= count_next;
    end
  end
  assign value = count;
endmodule
```

可以看到，`reg count: UInt<8> reset(rst, 0)` 干净地降级为同步高电平复位的 `always_ff @(posedge clk)` 块，并使用非阻塞赋值 `<=`。

## 第 4 步：编写 C++17 Verilator Testbench

创建 `tb_counter8.cpp`，依次测试复位、递增计数、保持与同步清零：

```cpp
#include "VCounter8.h"
#include "verilated.h"
#include <cassert>
#include <iostream>

int main(int argc, char** argv) {
    Verilated::commandArgs(argc, argv);
    VCounter8* dut = new VCounter8;

    auto tick = [&]() {
        dut->clk = 0;
        dut->eval();
        dut->clk = 1;
        dut->eval();
    };

    // 拉高同步复位
    dut->rst = 1;
    dut->enable = 0;
    dut->clear = 0;
    tick();
    assert(dut->value == 0);

    // 释放复位并计数 3 个周期
    dut->rst = 0;
    dut->enable = 1;
    for (int i = 1; i <= 3; ++i) {
        tick();
        assert(dut->value == i);
    }

    // enable = 0 时保持当前值
    dut->enable = 0;
    tick();
    assert(dut->value == 3);

    // 同步清零回 0
    dut->clear = 1;
    tick();
    assert(dut->value == 0);

    std::cout << "Counter8 Verilator testbench PASSED!" << std::endl;
    delete dut;
    return 0;
}
```

## 第 5 步：编译并运行仿真

调用 Verilator 将 `Counter8.sv` 转换为 C++，与 `tb_counter8.cpp` 联合编译并运行：

```bash
verilator --cc --exe --build -j 0 -CFLAGS "-std=c++17" \
  --top-module Counter8 Counter8.sv tb_counter8.cpp --Mdir obj_dir
./obj_dir/VCounter8
```

预期输出：

```text
Counter8 Verilator testbench PASSED!
```

## 常见踩坑与排障

- **忘记写 `next count := ...`**：没有 `next` 驱动的 `reg` 相当于触发器 `D` 端悬空，`sylc check` 会直接报错拦截。
- **混淆 `signal` 的 `:=` 与 `reg` 的 `next`**：组合逻辑 `signal` 使用 `name := expr`，而时序 `reg` 使用 `next name := expr`，以显式标出寄存器边界。
- **在 Verilator 中只设 `clk = 1`**：务必完整执行 `clk = 0; dut->eval(); clk = 1; dut->eval();`，Verilator 才能检测到上升沿（`posedge clk`）。
