---
title: 2. 时序计数器与 Verilator 仿真
description: 引入 Clock 与 Reset，编写同步计数器并使用 Verilator 进行周期级仿真。
---

本教程将带你编写一个带有 `Clock<D>` 与 `Reset<D, Sync, ActiveHigh>` 的 8 位同步计数器，生成 SystemVerilog，并使用 Verilator 进行 lint 与 C++17 周期级仿真。

## 第一步：编写 `counter.syl`

```syl
cell Counter8<D: Domain>(
    clk: in Clock<D>,
    rst: in Reset<D, Sync, ActiveHigh>,
    en: in Bit,
) -> count: UInt<8> {
    reg q: UInt<8> reset(rst, 0)
    next q := select {
        en => q + 1,
        default => q,
    }
    count := q
}
```

`Clock<D>` 与 `Reset<D, Sync, ActiveHigh>` 共享同一个时钟域参数 `D`。编译器会在编译期校验 `rst` 与 `clk` 是否属于同一时钟域。

## 第二步：检查与发射 SystemVerilog

```bash
sylc check counter.syl
sylc emit counter.syl --out counter.sv
```

## 第三步：使用 Verilator 进行 Lint 与仿真

```bash
verilator --lint-only --sv --top-module Counter8 counter.sv
```

配合 C++17 testbench `counter_test.cpp` 运行周期级仿真：

```bash
verilator --cc --exe --build -j 2 --sv --top-module Counter8 \
  -CFLAGS "-std=c++17" counter.sv counter_test.cpp -o sim
./obj_dir/sim
```
