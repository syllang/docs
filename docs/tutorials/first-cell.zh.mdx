本教程将带你编写一个最小化的组合逻辑 `cell`，使用 `sylc check` 运行静态检查，并使用 `sylc emit` 生成 SystemVerilog。

## 前置条件

- Rust 工具链（`rustc` / `cargo`）
- 从 `syllang/syl`（`origin/main` `7608b0d`）编译安装 `sylc`：

```bash
cargo install --path crates/sylc
sylc --version
```

## 第一步：编写 `adder.syl`

创建文件 `adder.syl`：

```syl
cell Adder8(
    a: in UInt<8>,
    b: in UInt<8>,
) -> sum: UInt<8> {
    sum := a + b
}
```

每个 `cell` 都声明带方向与类型的端口（`in` 或输出端口），并通过 `:=` 对每个输出进行**单次确定性驱动**。

## 第二步：运行 `sylc check`

```bash
sylc check adder.syl
```

当没有位宽不匹配、缺失驱动或多重驱动冲突时，`sylc check` 返回退出码 `0`。

如需结构化 JSON 诊断输出：

```bash
sylc check --diagnostics-format json adder.syl
```

## 第三步：生成 SystemVerilog

```bash
sylc emit adder.syl --out adder.sv
```

`sylc emit` 会将通过检查的 HWIR 降级为确定性的 SystemVerilog 代码。
