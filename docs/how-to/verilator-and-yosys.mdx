Syl's standard library is verified end-to-end by `scripts/check_std_sim.sh`, which runs 13 C++17 Verilator cycle-accurate simulations and 4 Yosys synthesis checks.

## Run the Standard Library Verification Suite

```bash
./scripts/check_std_sim.sh
```

The script:
1. Emits SystemVerilog for `pulse`, `skid`, `arbiter`, `cdc`, `mem`, and `fifo`.
2. Runs `verilator --lint-only --sv` on each top module.
3. Compiles and executes 13 C++17 Verilator testbenches (`tests/sim/*_test.cpp`).
4. Runs Yosys (`proc; memory; check -assert; stat`) on `SinglePortRam`, `SimpleDualPortRam`, `DistributedRam`, and `Sync2FFAsyncLow`.
