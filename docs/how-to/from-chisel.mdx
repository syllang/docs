Chisel embeds hardware construction in Scala; Syl is a standalone language with a built-in elaboration phase. You get similar expressive power (`for` unrolling, `bundle`, `interface`, `Stream`) without JVM startup overhead or runtime-vs-elaboration confusion.

## Concept Mapping

| Chisel (Scala) | Syl | Notes |
| :--- | :--- | :--- |
| `class Foo extends Module` | `cell Foo<D: Domain>(...)` | Explicit `Clock<D>` and `Reset<D, ...>`. |
| `IO(new Bundle { ... })` | `bundle` / `interface` | Directional `view` replaces `Flipped(...)`. |
| `Wire(UInt(8.W))` | `signal x: UInt<8> := ...` | Single `:=` driver. |
| `RegInit(0.U(8.W))` | `reg x: UInt<8> reset(rst, 0)` | Updated via `next x := ...`. |
| `MuxCase` / `when` | `select priority { ... }` | Expression-oriented, always has `default`. |
| `Decoupled(T)` | `std.stream.Stream<T>` | `source` and `sink` views. |
| Scala `for (i <- 0 until n)` | `for i in 0..N { ... }` | Built-in elaboration loop. |

## Key Differences

- **No last-connect semantics**: Chisel's `when` / `:=` allows multiple assignments where the last one wins. Syl enforces a **single driver** (`:=` or `next`) per signal/register, using `select` for priority.
- **Standalone compiler**: `sylc` compiles directly to SystemVerilog in milliseconds without SBT/JVM.

## `when` / `.elsewhen` / `.otherwise` vs. `select`

In Chisel, `when (cond) { out := a } .elsewhen (cond2) { out := b } .otherwise { out := c }` uses last-connect semantics. In Syl, every `signal` and `reg` has a **single driver**, and priority is expressed directly with `select priority`:

```syl
signal result: UInt<8> := select priority {
    cond1 => a,
    cond2 => b,
    default => c,
}
```

## `DecoupledIO` vs. `std.stream.Stream`

Chisel's `Decoupled(new MyBundle)` and `Flipped(Decoupled(...))` map to Syl's `Stream<MyBundle>.source` and `Stream<MyBundle>.sink`:

```syl
use std.stream.Stream

bundle MyBundle {
    data: UInt<32>,
    last: Bit,
}

cell PassThrough(
    in_s: in Stream<MyBundle>.sink,
    out_s: out Stream<MyBundle>.source,
) {
    out_s.payload := in_s.payload
    out_s.valid := in_s.valid
    in_s.ready := out_s.ready
}
```

## Elaboration: Scala Host vs. Built-in `fn` / `for` / `if`

In Chisel, you write Scala `for` loops and `if` statements that execute on the JVM to build FIRRTL. In Syl, `fn`, `const`, `for`, and `if` are built into the language and checked statically by `sylc`:

```syl
fn is_pow2(n: Nat) -> Bool {
    return n > 0 and (n & (n - 1)) == 0
}

cell FifoShell<DEPTH: Nat, D: Domain>(
    clk: in Clock<D>,
    rst: in Reset<D, Sync, ActiveHigh>,
) {
    if !is_pow2(DEPTH) {
        compile_error("DEPTH must be a power of two")
    }
}
```

## Migration Summary

| Chisel Concept | Syl Equivalent |
| :--- | :--- |
| `Module` + `IO(...)` | `cell` with typed `in`/`out`/`inout` ports |
| `Wire` + `:=` (last-connect) | `signal` + `:=` (single driver) + `select` |
| `RegInit` | `reg ... reset(rst, val)` + `next` |
| `VecInit` / `Vec` | `[N] T` fixed-size array |
| `BlackBox` | `extern cell` + Opaque Summary |
