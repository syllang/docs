---
title: Write CDC Synchronizers & Async Resets
description: Use @cdc_sync and Reset<D, Async, ActiveLow> safely.
---

Syl enforces clock-domain crossing (CDC) and reset polarity rules statically with zero new global keywords.

## Asynchronous Active-Low Reset

Use `Reset<D, Async, ActiveLow>` in port signatures and `reg ... reset(..., async, active_low)`:

```syl
cell AsyncLowReg<D: Domain>(
    clk: in Clock<D>,
    rst_n: in Reset<D, Async, ActiveLow>,
    d: in Bit,
) -> q: Bit {
    reg r: Bit reset(rst_n, 0)
    next r := d
    q := r
}
```

If `rst_n` belongs to a different domain than `clk`, Syl emits `E_MIDDLE_RESET_DOMAIN_MISMATCH`.

## Explicit CDC with `@cdc_sync`

Use `@cdc_sync(in, out, dst_clk)` to mark intentional clock-domain crossings (note: `inplace` is forbidden on `@cdc_sync`). For standard two-flop and pulse synchronizers, import `std.cdc.Sync2FF`, `std.cdc.Sync2FFAsyncLow`, or `std.cdc.PulseSynchronizer`.
