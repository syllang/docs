SpinalHDL and Syl share many design philosophies: both treat clock domains as first-class concepts and provide `Stream` handshakes out of the box.

## Concept Mapping

| SpinalHDL | Syl | Notes |
| :--- | :--- | :--- |
| `Component` | `cell` | Structural hardware unit. |
| `ClockDomain` | `Domain` + `Clock<D>` + `Reset<D, ...>` | Checked statically across `cell` boundaries. |
| `Reg(UInt(8 bits)) init(0)` | `reg r: UInt<8> reset(rst, 0)` | Single `next r := ...` assignment. |
| `Stream[T]` (`master`/`slave`) | `Stream<T>` (`source`/`sink`) | Directional `view`s. |
| `switch` / `is` | `match` (on `enum`) / `select` | `match` is statically exhaustive. |
| `BlackBox` | `extern cell` + Opaque Summary | Supports `domain_behavior` and `cdc_crossings`. |

## Clock Domains

In SpinalHDL, `ClockDomain` is passed implicitly via `ClockingArea`. In Syl, `D: Domain` is an explicit type parameter on `cell`, `Clock<D>`, and `Reset<D, Mode, Polarity>`, making cross-domain mistakes impossible to miss in code review or compilation.
