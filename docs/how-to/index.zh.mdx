本栏目提供面向具体工程目标的实操指南。所有 `.syl` 代码示例与配置片段均已通过 `sylc` 实测验证。

## 工程与工具链

- [配置 syl.toml](/zh/docs/how-to/configure-syl-toml)：配置 `[project]`、`[paths]`、多包工作区与自动向上发现。
- [使用 sylc](/zh/docs/how-to/sylc)：运行 `sylc check` 与 `sylc emit`、JSON 诊断输出与 `SourceMap` 渲染。
- [SystemVerilog 发射](/zh/docs/how-to/systemverilog-emission)：多文件发射（`--out-dir`）、`--filelist`、`--source-comments` 与确定性跨模块命名消歧。
- [外部模块与 IP 集成](/zh/docs/how-to/extern-and-ip)：编写 JSON/TOML Opaque Summary（`schema_version = 1`）、`domain_behavior` 与 `cdc_crossings`。
- [LSP 与编辑器](/zh/docs/how-to/lsp-and-editors)：配置 `syl-lsp`、`syl.toml` 热重载、增量同步与后台异步 DRC 通道。
- [Rust 嵌入](/zh/docs/how-to/rust-embedding)：在 Rust 工具中嵌入 `syl_session::AnalysisHost` 与 `AnalysisSnapshot`（`Send + Sync`）。
- [AI 编程助手提示词](/zh/docs/how-to/ai-prompt)：用于生成合法 Syl 硬件代码的生产级系统提示词。
