---
title: Emit Multi-File SystemVerilog & filelist.f
description: Use sylc check and sylc emit with --out-dir, --filelist, and --source-comments.
---

When a design spans multiple packages, `sylc emit` generates an `EmittedSvBundle` with one SystemVerilog file per module and a topologically ordered `filelist.f`.

## Emit a Multi-File Bundle

```bash
sylc emit src/top.syl \
  --out-dir build/sv \
  --filelist build/sv/filelist.f \
  --source-comments
```

## Deterministic Name Disambiguation

- Non-conflicting cells and `extern cell` declarations keep their short names.
- Conflicting cells across packages are disambiguated deterministically as `pkg__Cell` with an FNV-1a secondary suffix when needed.

## Human vs. JSON Diagnostics

```bash
sylc check --diagnostics-format human src/top.syl
sylc check --diagnostics-format json src/top.syl
```

Human mode renders `SourceMap`-backed source context; JSON mode emits structured diagnostics for CI pipelines.
