---
title: From VHDL
description: Migrate from VHDL to Syl, mapping entity/architecture, process, signal/variable, and generate statements.
---

VHDL engineers will find Syl's strong typing and explicitness familiar, but with far less boilerplate: `entity` and `architecture` are unified into a single `cell`, and `std_logic` ambiguity is replaced by `Bit` and `UInt<W>`.

## Concept Mapping

| VHDL | Syl | Notes |
| :--- | :--- | :--- |
| `entity` + `architecture` | `cell` | Single unified declaration. |
| `std_logic` | `Bit` | Strictly two-state (`0` / `1`). |
| `unsigned(W-1 downto 0)` | `UInt<W>` | Exact width checked at compile time. |
| `process(clk)` | `reg` + `next` | Implicitly bound to `Clock<D>`. |
| `process(all)` | `signal` + `select` / `match` | Exhaustive, latch-free combinational logic. |
| `generic (...)` | `<W: Nat, D: Domain>` | Type-level and `const` parameters. |
| `record` | `bundle` | Composable with `interface` views. |
| `for i in 0 to N-1 generate` | `for i in 0..N { ... }` | Elaboration-time unrolling. |

## Example: Entity + Process to `cell`

```syl
cell Register8<D: Domain>(
    clk: in Clock<D>,
    rst: in Reset<D, Sync, ActiveHigh>,
    d: in UInt<8>,
    en: in Bit,
    q: out UInt<8>,
) {
    reg r: UInt<8> reset(rst, 0)
    next r := select {
        en => d,
        default => r,
    }
    q := r
}
```

## Combinational Logic: `process(all)` vs. `signal` + `select`

In VHDL, combinational processes require listing all sensitivity signals (or `process(all)` in VHDL-2008) and assigning defaults to avoid latches. Syl's `select priority` and `match` are expressions that always produce a value:

```syl
signal mux_out: UInt<8> := select priority {
    sel == 0 => in0,
    sel == 1 => in1,
    default => 0,
}
```

## Records & Arrays

VHDL `record` types map to Syl `bundle`, and constrained arrays `array (0 to N-1) of ...` map to `[N] T`:

```syl
bundle AxiBeat {
    data: UInt<32>,
    last: Bit,
}

cell BeatDelay<N: Nat, D: Domain>(
    clk: in Clock<D>,
    rst: in Reset<D, Sync, ActiveHigh>,
    din: in AxiBeat,
    dout: out AxiBeat,
) {
    reg pipe: [N] AxiBeat reset(rst, AxiBeat { data: 0, last: 0 })
    next pipe[0] := din
    for i in 1..N {
        next pipe[i] := pipe[i - 1]
    }
    dout := pipe[N - 1]
}
```

## Migration Checklist for VHDL Engineers

| VHDL Habit | Syl Replacement |
| :--- | :--- |
| Separate `entity` and `architecture` | Single `cell` declaration. |
| `std_logic` (`'0'`, `'1'`, `'X'`, `'Z'`) | `Bit` (`0`, `1`); `inout` only at external pads. |
| `variable` vs. `signal` inside `process` | Use `signal` for wires and `reg` + `next` for state. |
| `generic` map | `<W: Nat, D: Domain>` type/const parameters. |
