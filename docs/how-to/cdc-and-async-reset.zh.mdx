---
title: 编写 CDC 同步器与异步低有效复位
description: 使用 @cdc_sync 与 Reset<D, Async, ActiveLow>。
---

Syl 在不引入任何新全局关键字的前提下，静态检查跨时钟域（CDC）与复位极性一致性。

## 异步低有效复位

在端口中使用 `Reset<D, Async, ActiveLow>`，并在寄存器声明中使用 `reg ... reset(..., async, active_low)`：

```syl
cell AsyncLowReg<D: Domain>(
    clk: in Clock<D>,
    rst_n: in Reset<D, Async, ActiveLow>,
    d: in Bit,
) -> q: Bit {
    reg r: Bit reset(rst_n, 0)
    next r := d
    q := r
}
```

如果复位信号与时钟属于不同时钟域，编译器将报出 `E_MIDDLE_RESET_DOMAIN_MISMATCH`。

## 使用 `@cdc_sync` 显式跨时钟域

使用 `@cdc_sync(in, out, dst_clk)` 标注合法的跨时钟域边界（注意：`@cdc_sync` 禁止 `inplace`）。对于常规两级触发器或脉冲同步器，可直接复用 `std.cdc.Sync2FF`、`std.cdc.Sync2FFAsyncLow` 与 `std.cdc.PulseSynchronizer`。
