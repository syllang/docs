---
title: 通过 Opaque Summary 接入黑盒 IP
description: 使用 schema_version = 1 的 JSON/TOML 摘要描述 extern cell。
---

为了在不丧失静态 CDC 与驱动检查的前提下接入厂商黑盒 IP（`extern cell`），可通过 JSON 或 TOML 提供外部 Opaque Summary（`schema_version = 1`）。

## JSON 摘要示例

```json
{
  "schema_version": 1,
  "summaries": [
    {
      "kind": "extern_cell",
      "callable": "vendor.VendorAsyncFifo",
      "endpoints": [],
      "domain_behavior": "unknown"
    }
  ]
}
```

## 在 `syl.toml` 中注册

```toml
[paths]
opaque_summaries = ["vendor/ip_summaries.json"]
```

运行 `sylc check --manifest syl.toml` 时会自动校验 `schema_version == 1` 并加载所有 `summaries` 到 `OpaqueSummaryTable`。
