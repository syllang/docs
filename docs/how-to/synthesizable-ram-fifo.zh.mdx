---
title: 建模可综合 RAM 与 FIFO
description: 使用 mem、mem_write、mem_read_sync 以及 std.mem / std.fifo。
---

Syl 提供可综合的存储器原语（`mem`、`mem_write`、`mem_read_sync`、组合索引与 `let` 别名），可降级为 Verilator 与 Yosys 均能正确综合推断的标准 SystemVerilog 存储器阵列。

## 存储器原语

- `mem m: UInt<W>[DEPTH]`：声明存储器阵列。
- `mem_write(m, clk, we, waddr, wdata)`：同步写操作。
- `mem_read_sync(m, clk, re, raddr)`：同步读操作。
- `m[addr]`：组合读（用于分布式 RAM）。

## 标准库封装

在工程实践中推荐直接使用 `std.mem`（`SinglePortRam`、`SimpleDualPortRam`、`DistributedRam`）与 `std.fifo`（`SyncFifo`、`StreamSyncFifo`），均已通过 Verilator 仿真与 Yosys 综合验证。
