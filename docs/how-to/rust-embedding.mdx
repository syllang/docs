# Rust Embedding

The Syl compiler is written in Rust and can be embedded as a library into custom build tools, CI runners, and editor plugins. This guide shows how to use the Rust API.

---

## Adding Dependencies

Add the crates to your `Cargo.toml`:

```toml
[dependencies]
syl_session = { git = "..." }
syl_emit = { git = "..." }
```

## Basic Usage (`AnalysisHost` & `AnalysisSnapshot`)

```rust
use syl_session::{AnalysisHost, DocumentUri, DocumentVersion};

let mut host = AnalysisHost::new();
let uri = DocumentUri::new("example.syl");
host.open_document(uri.clone(), source_code.to_string(), DocumentVersion::new(1));
let snapshot = host.snapshot()?;
```

`AnalysisSnapshot` implements `Send + Sync`, so you can move it to a background thread for non-blocking diagnostics:

```rust
use syl_session::{AnalysisHost, ProjectConfig};
use std::path::Path;

let mut host = AnalysisHost::new(ProjectConfig::from_manifest(Path::new("syl.toml"))?);
host.open_document("src/top.syl", source_code.to_string(), 1);
let snapshot = host.snapshot();

std::thread::spawn(move || {
    let diags = snapshot.diagnostics();
    for d in &diags {
        eprintln!("{d}");
    }
});
```

## Compiling & Emitting SystemVerilog (`EmitOptions`)

```rust
use syl_emit::{EmitOptions, SystemVerilogBackend};
use syl_sema::SemanticCompiler;
use syl_elab::HardwareCompiler;
use syl_syntax::SourceParser;

let file = SourceParser::new(source).parse_file()?;
let sema = SemanticCompiler::new().session(&[file]);
let hir = sema.resolve_hir()?;
let tir = hir.check_tir()?;
let hwir = HardwareCompiler::new().compile_tir(&tir)?;

let opts = EmitOptions {
    source_comments: true,
    ..EmitOptions::default()
};
let sv = SystemVerilogBackend::with_options(opts).emit(&hwir)?;
```

## Retrieving Diagnostics

```rust
let snapshot = host.snapshot()?;
let diagnostics = snapshot.diagnostics();
for diagnostic in &diagnostics {
    println!("{}", diagnostic);
}
```

## Query API

```rust
use syl_query::AnalysisQueries;

let snapshot = host.snapshot()?;
let hover = snapshot.hover_at(uri, position)?;
let definition = snapshot.definition_at(uri, position)?;
let completions = snapshot.completions_at(uri, position)?;
```
