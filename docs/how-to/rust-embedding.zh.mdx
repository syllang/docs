Syl 编译器使用 Rust 编写，提供模块化 crate（`syl_session`、`syl_syntax`、`syl_sema`、`syl_elab`、`syl_emit`、`syl_query`），可直接嵌入到自定义构建工具、CI 检查器与编辑器插件中。

## 添加依赖

```toml
[dependencies]
syl_session = { path = "crates/syl_session" }
syl_emit = { path = "crates/syl_emit" }
```

## 会话管理：`AnalysisHost` 与 `AnalysisSnapshot`

`syl_session::AnalysisHost` 负责管理项目配置（`syl.toml`）、虚拟文件系统（VFS）状态与增量更新。调用 `host.snapshot()` 会生成一个不可变的 `AnalysisSnapshot`；该快照实现了 `Send + Sync`，可安全地发送到后台线程执行耗时查询与 DRC，而不会阻塞主线程的编辑操作。

```rust
use syl_session::{AnalysisHost, ProjectConfig};
use std::path::Path;

let mut host = AnalysisHost::new(ProjectConfig::from_manifest(Path::new("syl.toml"))?);
host.open_document("src/top.syl", source_code.to_string(), 1);

let snapshot = host.snapshot();
// `snapshot` 实现了 Send + Sync，可安全跨线程传递
let diagnostics = snapshot.diagnostics();
for diag in &diagnostics {
    println!("{diag}");
}
```

## 编译与发射 SystemVerilog（`EmitOptions`）

使用 `EmitOptions` 配置单文件/多文件发射以及是否附带源码位置注释：

```rust
use syl_emit::{EmitOptions, SystemVerilogBackend};

let options = EmitOptions {
    source_comments: true,
    ..EmitOptions::default()
};
let sv_output = SystemVerilogBackend::with_options(options).emit(&hwir)?;
```

## 语义查询 API

`AnalysisSnapshot` 同时提供与 LSP 同源的语义查询接口：

```rust
let hover = snapshot.hover_at("src/top.syl", position)?;
let definition = snapshot.definition_at("src/top.syl", position)?;
let completions = snapshot.completions_at("src/top.syl", position)?;
```

## 适用场景

- 自定义硬件构建系统与 Bazel/Cargo 集成
- 自动化 CI 静态检查与 DRC 门禁
- 编辑器插件与在线 Playground
- 基于属性的硬件测试框架
