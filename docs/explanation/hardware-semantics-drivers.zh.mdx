在 Syl 中，`cell` 体描述的是结构化的硬件连接关系，而非命令式控制流：

- **连续赋值（`:=`）** 将信号绑定到唯一的组合逻辑表达式。
- **时序寄存器（`reg ... reset(...)` + `next`）** 将状态更新绑定到明确的 `Clock<D>` 与 `Reset<D, ...>`。
- **存储器（`mem`）** 通过显式的 `mem_write`、`mem_read_sync` 与组合索引原语建模。

在展开（Elaboration）阶段，`syl_elab` 会为每条网络构建驱动事实，并在降级到 `syl_hw` 之前验证驱动完整性与无重叠性。
