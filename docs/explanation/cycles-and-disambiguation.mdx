## Cycle Rules

As specified in `docs/query-driven-cycles.md`, a Salsa query cycle is never a Syl language diagnostic. Language cycles are handled deterministically in `syl_sema` and `syl_elab`:

- **Mutual `use` imports** of valid symbols are allowed.
- **Const cycles** produce `E_MIDDLE_CONST_CYCLE` on each cyclic initializer.
- **Recursive `struct` / `bundle`** layouts produce `E_MIDDLE_RECURSIVE_STRUCT` / `E_MIDDLE_RECURSIVE_BUNDLE` (polymorphic expansion depth bounded at 64).
- **Duplicate module files** produce `E_DUPLICATE_MODULE_FILE` and deterministically select the first URI in lexical order.

## Cross-Module Name Disambiguation

During SystemVerilog emission (`syl_emit`), non-conflicting cells and `extern cell` declarations keep their short names. Conflicting names across packages are disambiguated as `pkg__Cell` with an FNV-1a secondary suffix when collisions remain.
