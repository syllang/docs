---
title: 编译管线
description: 从 Syntax AST 到 HIR、TIR、EIR、HWIR 再到 SystemVerilog 的完整管线。
---

Syl 通过六个确定性阶段将源码降级为 SystemVerilog：

1. **Syntax（`syl_syntax`）**：词法与语法解析，生成带 `SourceMap` 偏移的 `Arc<ParsedFileOutput>`。
2. **HIR（`syl_hir`）**：模块组装、`use` 导入解析与 `E_DUPLICATE_MODULE_FILE` 检测。
3. **TIR（`syl_sema`）**：类型推导、`check_fn` / `check_map`、常量求值（10,000 步上限）与递归布局检查。
4. **EIR（`syl_elab`）**：Per-module 展开、map 内联、驱动事实收集、CDC 与复位域 DRC。
5. **HWIR（`syl_hw`）**：硬件网表中间表示。
6. **SystemVerilog（`syl_emit`）**：多文件 `EmittedSvBundle`、确定性命名消歧与拓扑有序的 `filelist.f`。
