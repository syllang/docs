# Syl 文档

Syl 是一门静态可分析的硬件描述语言（HDL），旨在生成 SystemVerilog 之前就在编译期捕获硬件缺陷——包括缺失驱动、多驱动冲突、位宽不匹配、跨时钟域（CDC）违规以及复位域/极性不一致。

## 生产级 Syl 全貌

### Salsa 增量编译引擎
Syl 编译器（`sylc`）与语言服务器（`syl_lsp`）共享一套基于 **Salsa 的增量查询数据库**。编辑单个 `.syl` 文件时，仅重新计算受影响的语法、HIR/TIR、展开与静态检查查询，在编辑器中提供亚秒级诊断反馈，并在 CI 中实现极速增量构建。详见 [Salsa 增量架构](/zh/docs/explanation/salsa-incremental-architecture)。

### `syl.toml` 工作区与包清单
多文件工程通过 `syl.toml` 配置，用于定义包名、源码根目录、SystemVerilog 生成目标选项以及 `extern` IP 绑定。详见 [配置 `syl.toml`](/zh/docs/how-to/configure-syl-toml) 与 [Manifest 与 Opaque Schema](/zh/docs/reference/manifest-and-opaque-schema)。

### 编译期静态硬件保证
每次执行 `sylc check` 都会验证：
- **驱动完整性与排他性**：杜绝悬空未驱动输出（`E_MIDDLE_UNDRIVEN_OUT`）与多驱动冲突（`E_MIDDLE_DUPLICATE_HARDWARE_DRIVER`）。
- **位宽与类型安全**：精确位宽匹配（`E_MIDDLE_TYPE_MISMATCH`）以及 `Bool` 与 `Bit` 的严格区分。
- **跨时钟域与复位域检查（CDC/RDC）**：显式的 `Clock<D>` 与 `Reset<D>` 域追踪（`E_MIDDLE_CDC_VIOLATION`）、复位极性一致性检查，以及可综合 RAM/FIFO 推断。

详见 [诊断索引](/zh/docs/explanation/diagnostic-index) 与 [诊断参考手册](/zh/docs/reference/diagnostics)。

### 13 个 `std.*` 标准库模块
Syl 内置 13 个标准库模块，涵盖算术运算、位操作、跨时钟域同步器、FIFO、存储器、仲裁器与总线协议。详见 [标准库参考](/zh/docs/reference/standard-library) 与 [标准库使用模式](/zh/docs/how-to/standard-library)。

### `syl_lsp` 与编辑器支持
`syl_lsp` 基于与 `sylc` 相同的 Salsa 数据库，提供实时诊断、悬停类型/位宽提示、跳转到定义与工作区符号搜索。详见 [LSP 与编辑器](/zh/docs/how-to/lsp-and-editors)。
