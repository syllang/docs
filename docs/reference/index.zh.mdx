# 参考手册

本手册涵盖 Syl 硬件描述语言、编译器（`sylc`）、标准库（`std.*`）、清单与 Opaque Summary Schema 以及工具链的完整技术规范。

## 设计思路

Syl 的类型系统和构造方式围绕一个核心目标设计：**让编译器在编译期尽可能多地检查硬件设计的正确性**。

这意味着 Syl 的类型信息比 Verilog 更丰富。编译器知道每个信号的位宽、方向、时钟/复位域以及能力（可读、可驱动、时钟、复位）。有了这些信息，编译器可以在生成 SystemVerilog 之前发现连接错误、位宽错误、驱动冲突和跨时钟域（CDC）违规。

## 类型系统概览

Syl 的类型分为三类：

- **基本类型。** `Bit`（单比特）、`Nat`（自然数，编译期使用）、`Bool`（布尔值，编译期使用）。
- **数值字类型。** `UInt<W>`（`W` 位无符号整数）。位宽 `W` 是一个自然数，在编译期确定。
- **复合类型。** `[N] T`（数组）、`bundle`（结构体）、`enum`（枚举）、`interface`（接口/端口组）。

## 核心构造方式

- **组合逻辑（`map`）。** 定义纯组合函数，输入输出关系在编译期确定，没有状态和副作用。
- **时序逻辑（`reg`、`next`、`mem`）。** 带有显式时钟/复位域、复位极性的寄存器以及可综合存储器。
- **硬件单元（`cell`、`extern cell`）。** 可参数化的硬件模块与外部/厂商黑盒单元。
- **接口与视图（`interface`、`view`）。** 将相关端口组合在一起，并定义不同连接方向看到的端口集合。
- **编译期构造（`const`、`fn`、`if`、`for`）。** 在编译期求值与展开，不生成额外硬件。
