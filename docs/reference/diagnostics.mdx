# Diagnostics

## Diagnostic Format

Compiler diagnostics follow this format:

```
<severity>[<code>]: <message>
  ┌─ <file>:<line>:<column>
  │
<line> │     <source>
  │         <highlight>
```

- `severity`: `error` or `warning`
- `code`: Diagnostic code, such as `E_MIDDLE_TYPE_MISMATCH`
- `message`: Description message

## Errors

### `E_SYNTAX_PARSE`

The parser encountered an unexpected token.

```
error[E_SYNTAX_PARSE]: expected item, found `@`
```

Check for typos or stray characters in the source file.

### `E_MIDDLE_UNRESOLVED_NAME`

Name resolution failed to find the referenced identifier.

```
error[E_MIDDLE_UNRESOLVED_NAME]: name `Counter` not found in this scope
```

Verify that `use` imports and identifier spellings are correct.

### `E_IMPORT_RESOLVE`

Import resolution failed or formed a cycle.

```
error[E_IMPORT_RESOLVE]: circular import detected
```

Check package dependencies and break any import cycles.

### `E_MIDDLE_TYPE_MISMATCH`

Type mismatch between expected and actual types.

```
error[E_MIDDLE_TYPE_MISMATCH]: expected `UInt<8>`, found `Bit`
    ┌─ input.syl:2:9
    │
2   │     y := x
    │         ^ expected `UInt<8>`, found `Bit`
```

Check that both sides of the assignment have matching types and bit widths.

### `E_MIDDLE_NOT_DRIVABLE`

Capability violation: attempted an invalid operation on a port.

```
error[E_MIDDLE_NOT_DRIVABLE]: cannot drive `in` port `x`
    ┌─ input.syl:2:5
    │
2   │     x := 1
    │     ^ `x` is declared as `in`
```

`in` ports cannot be driven, and `out` ports cannot be read.

### `E_MIDDLE_DUPLICATE_HARDWARE_DRIVER`

Multiple-driver conflict: the same signal is driven by more than one source.

```
error[E_MIDDLE_DUPLICATE_HARDWARE_DRIVER]: duplicate hardware driver for `y`
    ┌─ input.syl:2:5
    │
2   │     y := 1
    │     ^ first driver
3   │     y := 2
    │     ^ duplicate driver
```

Every signal may have only one driver. Combine conditional assignments using `select`.

### `E_MIDDLE_UNKNOWN_TYPE`

Referenced an undefined type.

```
error[E_MIDDLE_UNKNOWN_TYPE]: unknown type `CustomType`
```

Check the type name spelling and ensure it is imported.

## Native simulation

**`E_SIM` (error, exit 1).** Simulation can fail during specialization, backend selection or execution. A failed `expect` reports the port and its observed value. A failed batch assertion reports its zero-based lane, global stimulus step, hierarchical assertion path and Syl source location. `--replay-vcd` records the verified failing trajectory.

**`W_SIM_UNIQUE` (warning).** A direct reference trace encountered multiple true guards in a `select unique`. The warning carries the guard overlap location. Warnings alone exit 0. With `--strict-unique` the overlap raises `E_SIM` and exits 1.

## Real `E_*` Error Code Index

- **Lexical & Syntax (`syl_syntax`)**: `E_SYNTAX_PARSE`, `E_SYNTAX_UNEXPECTED_CHARACTER`, `E_SYNTAX_UNSUPPORTED_STRING_ESCAPE`, `E_SYNTAX_UNTERMINATED_STRING`, `E_SYNTAX_DOC_COMMENT`
- **Project, Manifest & Opaque (`syl_session` / `sylc`)**: `E_CLI`, `E_IO`, `E_EMIT`, `E_PROJECT`, `E_IMPORT_RESOLVE`, `E_INVALID_MODULE_PATH`, `E_DUPLICATE_MODULE_FILE`, `E_MANIFEST_PARSE`, `E_MANIFEST_INVALID`, `E_OPAQUE_SUMMARY_PARSE`, `E_OPAQUE_SUMMARY_INVALID`
- **Semantic & Type Checking (`syl_sema`)**: `E_MIDDLE_TYPE_MISMATCH`, `E_MIDDLE_UNKNOWN_TYPE`, `E_MIDDLE_UNKNOWN_IMPORT`, `E_MIDDLE_UNRESOLVED_NAME`, `E_MIDDLE_UNKNOWN_ELAB_IDENTIFIER`, `E_MIDDLE_UNKNOWN_PARAMETER`, `E_MIDDLE_DUPLICATE_ARGUMENT`, `E_MIDDLE_TOO_MANY_POSITIONAL_ARGS`, `E_MIDDLE_MISSING_AGGREGATE_FIELD`, `E_MIDDLE_UNKNOWN_AGGREGATE_FIELD`, `E_MIDDLE_RECURSIVE_STRUCT`, `E_MIDDLE_RECURSIVE_BUNDLE`, `E_MIDDLE_DUPLICATE_CONST`, `E_MIDDLE_DUPLICATE_FN`, `E_MIDDLE_IMMUTABLE_ASSIGNMENT`, `E_MIDDLE_MISSING_RETURN`, `E_MIDDLE_RETURN_TYPE_MISMATCH`, `E_MIDDLE_HARDWARE_STMT_IN_FN`, `E_MIDDLE_BOOL_IN_HARDWARE_VALUE`, `E_MIDDLE_REQUIRES_NAT`, `E_MIDDLE_INVALID_ELAB_EXPR`, `E_MIDDLE_NOT_DRIVABLE`, `E_MIDDLE_CONTINUOUS_DRIVE_TO_REG`, `E_MIDDLE_DIRECT_DRIVE_TO_MEM`, `E_MIDDLE_INVALID_CDC_ATTR`, `E_MIDDLE_INVALID_RESET_QUALIFIER`, `E_MIDDLE_MEMORY_OP_STATEMENT_ONLY`, `E_MIDDLE_MEMORY_REQUIRES_ARRAY_TYPE`, `E_MIDDLE_MEMORY_TARGET_NOT_MEM`
- **Elaboration, DRC, CDC & Memory (`syl_elab`)**: `E_MIDDLE_CONST_CYCLE`, `E_MIDDLE_DUPLICATE_HARDWARE_DRIVER`, `E_MIDDLE_CDC_VIOLATION`, `E_MIDDLE_INPLACE_ON_CDC_SYNC`, `E_MIDDLE_RESET_DOMAIN_MISMATCH`, `E_MIDDLE_RESET_CONFIG_CONFLICT`, `E_MIDDLE_DUPLICATE_MEM_WRITE_PORT`
- **Backend & SystemVerilog Emission (`syl_sv`)**: `E_EMIT` (production CLI emission error; internal/conformance aliases include `E_HW_DUPLICATE_BINDING`, `E_HW_DUPLICATE_MODULE`, `E_HW_INVALID_IDENTIFIER`, `E_HW_UNKNOWN_INSTANCE_TARGET`, `E_HW_UNKNOWN_REFERENCE`, `E_SV_UNSUPPORTED_FUNCTION_CALL`)
- **Native simulation (`sylc`)**: `E_SIM`.
