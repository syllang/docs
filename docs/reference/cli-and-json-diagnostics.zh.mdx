## 子命令

- `sylc check <input.syl>`：执行 Parse、HIR、TIR 与全量展开/DRC 检查。
- `sylc emit <input.syl>`：检查并生成 SystemVerilog（单文件 `--out` 或多文件 `EmittedSvBundle` `--out-dir`）。

## 核心参数

| 参数 | 说明 |
| --- | --- |
| `--manifest <path>` | 显式指定 `syl.toml`，覆盖自动向上发现 |
| `--std-root <dir>` | 指定标准库根目录 |
| `--package-root <dir>` | 追加外部包根目录（可重复） |
| `--diagnostics-format human\|json` | `SourceMap` 源码上下文渲染或结构化 JSON |
| `--out <file>` | 单文件 SystemVerilog 输出路径 |
| `--out-dir <dir>` | 多文件 SystemVerilog 输出目录 |
| `--filelist <file>` | 输出拓扑有序的 `filelist.f` |
| `--source-comments` | 在生成的 SV 中保留 Syl 源码位置注释 |
