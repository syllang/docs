# Support

If you encounter a compiler bug, unclear diagnostic, or documentation gap:

- **Bug Reports & Feature Requests:** Open an issue in the Syl repository with a minimal `.syl` reproduction and the `sylc --version` output.
- **Diagnostics:** Include `--diagnostics-format json` output when reporting compiler errors.
