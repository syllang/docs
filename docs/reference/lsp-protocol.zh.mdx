---
title: syl_lsp 协议能力
description: 增量同步、异步后台 DRC、inlay hints、语义高亮、重命名与查找引用。
---

`syl_lsp` 基于 `syl_session` 与 Salsa 0.28.2 提供 stdio 模式的 LSP 服务。

| 能力 | 说明 |
| --- | --- |
| 文档同步 | `TextDocumentSyncKind::INCREMENTAL`（UTF-16 偏移映射） |
| 配置与监听 | 自动加载 `syl.toml`，通过 `didChangeWatchedFiles` 热重载 |
| 诊断通道 | 快路径 Parse/HIR/TIR + 低优先级可取消异步后台 Elaboration DRC |
| 导航 | `textDocument/definition`、`textDocument/references`、`workspace/symbol` |
| 重构 | `textDocument/prepareRename`、`textDocument/rename` |
| 智能提示 | `hover`、`completion`、`signatureHelp`、`inlayHint`（类型/位宽/时钟域）、`textDocument/semanticTokens/full` |
