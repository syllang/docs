---
title: Diagnostic Codes
description: Quick reference for real compiler diagnostic codes in Syl.
---

| Code | Stage | Meaning |
| --- | --- | --- |
| `E_SYNTAX_PARSE` | Syntax | Syntax parse error |
| `E_DUPLICATE_MODULE_FILE` | HIR Assembly | Multiple file URIs map to the same module path |
| `E_MANIFEST_PARSE` | Manifest | Failed to parse `syl.toml` |
| `E_OPAQUE_SUMMARY_PARSE` | Manifest | Failed to parse JSON/TOML opaque summary |
| `E_MIDDLE_UNKNOWN_IMPORT` | HIR | Imported symbol does not exist in target module |
| `E_MIDDLE_UNRESOLVED_NAME` | HIR / TIR | Identifier cannot be resolved in scope |
| `E_MIDDLE_TYPE_MISMATCH` | TIR | Incompatible types or bit widths |
| `E_MIDDLE_CONST_CYCLE` | TIR / EIR | Cyclic `const` definition |
| `E_MIDDLE_CONST_STEP_LIMIT` | TIR | Const evaluator exceeded 10,000 steps |
| `E_MIDDLE_RECURSIVE_STRUCT` | TIR | Infinite/recursive `struct` value layout |
| `E_MIDDLE_RECURSIVE_BUNDLE` | TIR | Infinite/recursive `bundle` value layout |
| `E_MIDDLE_REQUIRES_NAT` | TIR | Expression must evaluate to `nat` |
| `E_MIDDLE_UNSUPPORTED_HW_VALUE_EXPR` | EIR | Expression not supported by hardware value lowering (e.g. map cycle) |
| `E_MIDDLE_DUPLICATE_HARDWARE_DRIVER` | Elaboration / DRC | Multiple drivers on the same signal |
| `E_MIDDLE_UNDRIVEN_OUT` | Elaboration / DRC | Output port has no driver |
| `E_MIDDLE_CDC_VIOLATION` | Elaboration / DRC | Illegal clock-domain crossing without `@cdc_sync` |
| `E_MIDDLE_RESET_DOMAIN_MISMATCH` | Elaboration / DRC | Reset signal domain does not match register clock domain |
