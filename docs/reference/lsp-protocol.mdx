---
title: syl_lsp Protocol Capabilities
description: Incremental sync, async DRC, inlay hints, semantic tokens, rename, and references.
---

`syl_lsp` implements the Language Server Protocol over stdio on top of `syl_session` and Salsa 0.28.2.

| Capability | Details |
| --- | --- |
| Document Sync | `TextDocumentSyncKind::INCREMENTAL` with UTF-16 offset mapping |
| Config & Watch | Auto-loads `syl.toml`; hot-reloads on `didChangeWatchedFiles` |
| Diagnostics | Fast-path Parse/HIR/TIR + low-priority cancellable background elaboration DRC |
| Navigation | `textDocument/definition`, `textDocument/references` (`find_references`), `workspace/symbol` |
| Refactoring | `textDocument/prepareRename`, `textDocument/rename` |
| Assistance | `textDocument/hover`, `textDocument/completion`, `textDocument/signatureHelp`, `textDocument/inlayHint` (types/widths/clock domains), `textDocument/semanticTokens/full` |
