# Versioning and Compatibility

Syl follows Semantic Versioning (`MAJOR.MINOR.PATCH`).

- **Language & Standard Library:** Breaking syntax or `std.*` signature changes are documented in the [Changelog](./changelog).
- **Opaque Summary Schema:** Versioned via `schema_version` (currently `schema_version = 1`).
