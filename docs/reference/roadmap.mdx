# Roadmap

## Completed Milestones (Wave 0–3)

- **Wave 0–1:** Salsa incremental query architecture, `syl.toml` manifest discovery, full `fn` body checking, `map` return consistency, and declaration cycle detection.
- **Wave 2:** 13 `std.*` standard library modules, `--out-dir` / `--filelist` / `--source-comments`, JSON diagnostics, and `syl-lsp` semantic tokens + background DRC.
- **Wave 3:** CDC domain enforcement (`@cdc_sync`), `Reset` sync/polarity qualifiers, synthesizable `mem` primitives, and Opaque Summary `schema_version = 1`.

## Future Direction

- Expanded standard library protocols and formal verification integration.
- Additional LSP refactorings (rename, code actions, signature help).
