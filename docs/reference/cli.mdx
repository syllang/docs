# CLI Reference

`sylc` is the command-line entry point for the Syl compiler. It compiles Syl source files into SystemVerilog.

---

## Usage

```
sylc [OPTIONS] [FILE_OR_DIR]... [COMMAND]
```

### Subcommands

- `sylc check [OPTIONS] [FILE_OR_DIR]...`: Type-check and run elaboration DRC without emitting SystemVerilog.
- `sylc emit [OPTIONS] [FILE_OR_DIR]...`: Check and emit SystemVerilog to stdout, `--out`, or `--out-dir`.

## Basic Usage

Compile a single file and print to stdout:

```
sylc input.syl
```

Compile multiple files:

```
sylc file1.syl file2.syl
```

Write output to a file:

```
sylc input.syl --out output.sv
```

## Options

### `--manifest <PATH>`

Explicitly specify the `syl.toml` project manifest path.

### `--package-root <PATH>`

Explicitly specify the package root directory.

### `--std-root <PATH>`

Specify the standard library root path.

### `--out <OUTPUT>`

Write a single SystemVerilog file.

```
sylc input.syl --out build/output.sv
```

### `--out-dir <DIR>`

Write one SystemVerilog file per module and generate a dependency-ordered filelist.

### `--filelist <PATH>`

Set the filelist path (defaults to `<out-dir>/filelist.f`).

### `--source-comments`

Include Syl source locations in the emitted SystemVerilog.

### `--diagnostics-format <human|json>`

Set the diagnostics output format (default: `human`).

### `--help`

Print help information.

```
sylc --help
```

### `--version`

Print version information.

```
sylc --version
```

## Output

### Normal Output

On success, SystemVerilog code is written to stdout (or to `--out` / `--out-dir`).

### Diagnostics

Diagnostics are written to stderr. Each diagnostic includes:

- Severity (`error` or `warning`)
- Error code
- Description message
- Source location (file, line, column)

```
error[E_MIDDLE_TYPE_MISMATCH]: expected `UInt<8>`, found `Bit`
  ┌─ input.syl:2:9
  │
2 │     y := x
  │         ^ expected `UInt<8>`, found `Bit`
```

### JSON Diagnostics Output Schema

When `--diagnostics-format json` is used, each diagnostic is emitted as structured JSON containing `code`, `severity`, `message`, and `span` (file, line, column) for CI and editor integration.

### Exit Codes

- `0`: Compilation succeeded
- `1`: Compilation failed (error diagnostics present)
