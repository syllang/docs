## Subcommands

- `sylc check <input.syl>`: Run Parse, HIR, TIR, and full elaboration/DRC checks.
- `sylc emit <input.syl>`: Check and emit SystemVerilog (`--out` for single file, `--out-dir` for multi-file `EmittedSvBundle`).

## Key Flags

| Flag | Description |
| --- | --- |
| `--manifest <path>` | Override automatic `syl.toml` discovery |
| `--std-root <dir>` | Set standard library root |
| `--package-root <dir>` | Add external package root (repeatable) |
| `--diagnostics-format human\|json` | Render `SourceMap` context or structured JSON |
| `--out <file>` | Single-file SystemVerilog output |
| `--out-dir <dir>` | Multi-file SystemVerilog output directory |
| `--filelist <file>` | Emit topologically ordered `filelist.f` |
| `--source-comments` | Include Syl source location comments in emitted SV |
